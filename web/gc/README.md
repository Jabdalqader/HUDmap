# web/gc/ (T1.5): Ground Control

Open `/gc/` on a laptop, type the room code shown on the astronaut's HUD (under COMMS), press **Connect**.

- **Astronaut view:** live video of exactly what the astronaut sees (camera or 3D Mars, with the HUD).
- **Mars map:** HiRISE (Mars Trek) with Curiosity's route, the stops, and the astronaut's live position and trail.
- **Readouts:** oxygen, radiation dose, next stop, distances, heading. **Alert log.**
- **Message to astronaut**, **Mars delay** switch (20 s demo up to 22 min; video stays live), **events:** dust storm, solar storm, O₂ leak, steep ground.
- Libraries: `vendor/leaflet.*` (Leaflet 1.9.4, BSD-2).
