# web/mission/ (AI1)
`mission.json` + `assets/` (stop photos, panoramas, layer images). Generated by `builder/`. Format: docs/system-design.md section 7.

## The official mission file
`web/mission/mission.json` is built by `python3 builder/build_official_mission.py` (Curiosity waypoints + REMS weather + RAD average + AI1's stop photos). It carries the fields every part reads (HUD, voice, sim). After changing it, rebuild the voice module: `cd ai && npm run build:hud`.
